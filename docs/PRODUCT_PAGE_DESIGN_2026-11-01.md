# Public product site — design authority

The current `/about` and `/about.html` design is the user-pinned Aether Flow redesign: forest ground, ivory and celadon, Bricolage Grotesque Variable display, Hanken Grotesk Variable body, three credited Kenyan photographs and spacious scrolling. Its token-bearing authority is [src/features/product/DESIGN.md](../src/features/product/DESIGN.md), paired with [the scoped sidecar](../src/features/product/.impeccable/design.json). The [six-block brief](PRODUCT_PAGE_BRIEF.md) governs the public page's composition and behavior.

The initial public iteration extended Waterline with Manrope/DM Sans, pale blue fields and manual explorers. That iteration is superseded for these two public routes. Root [DESIGN.md](../DESIGN.md), root `.impeccable/design.json` and [Waterline](WATERLINE.md) still govern the working Operate application. This repository has a public Persuade world and a working Operate world; the public redesign does not migrate global tokens.

The user supplied the 21st.dev Aether Flow hero and requested the new typography, web photography, open spacing and automatic explanations. No new Impeccable concept roll or QUALITY BAR card applies. Taste's separate dark-room direction record uses seed `542333872`; the pinned hero replaces its ring composition, OFL public fonts replace Erode for redistribution clarity, and contextual Kenyan photographs replace atmospheric water. Preserved sandbox evidence replaces fictional customer logos.
